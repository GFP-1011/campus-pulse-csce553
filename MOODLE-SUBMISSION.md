## Project Summary

Campus Pulse is the CSCE 553 M1 Option A social-media baseline. It provides a public browser UI and JSON HTTP API for registration, login/logout, adding friends, creating and reading messages, editing messages, and liking messages. The application is deployed from GitHub to Render and stores persistent data in Supabase PostgreSQL.

This is a course-only baseline system, not a production service. All demo accounts and content are fake.
